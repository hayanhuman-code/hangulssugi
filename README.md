# 한글쓰기연습 (hangulssugi)

만 4세를 위한 한글·숫자 쓰기 연습 웹앱. Claude Design 시안
「쓰기연습 앱 화면 시안 v2」를 그대로 구현했습니다.

가로 태블릿 **1180 × 820** 기준으로 그리고, 창 크기에 맞춰 화면 전체를
비율 그대로 축소합니다. 채점도 오답 표시도 없습니다.

## 실행

`index.html` 을 브라우저에서 열면 끝입니다. 빌드 도구도 서버도 필요 없습니다.

```bash
# 로컬 서버로 보고 싶다면
npx http-server -p 8080 .
```

## 화면

| 화면 | 내용 |
|---|---|
| 홈 · 학습 선택 | 탭 5개(숫자 21 · 자음 19 · 모음 21 · 글자 15 · 단어 16), 항목 수에 따라 7열 / 5열 / 4열 그리드 |
| 1단계 · 보기 | 획순 애니메이션이 계속 반복 |
| 2단계 · 따라쓰기 | 3층 점선 가이드 위에 아이가 그은 선이 얹힘 |
| 3단계 · 혼자쓰기 | 아주 흐린 외곽선만, 번호·화살표 없음 |
| 다 했어요 | 별·컨페티, 다음 쓰기 / 홈으로 |

### 획 가이드 3층 구조

시안의 핵심 규칙 그대로입니다. 굵은 선에 점선 패턴을 넣지 않고, 세 층을
각각 다른 요소로 그려 명도(16% → 70% → 100%)와 굵기(110 → 12.5 → 아이콘)로
대비를 만듭니다.

1. **넓은 띠** — 굵기 110, 카테고리 딥색 16%
2. **가는 점선** — 굵기 12.5, 딥색 70%, 띠의 정중앙 패스를 그대로 공유
3. **시작 번호 + 방향 화살표** — 딥색 100%, 지금 그을 획에만

아이가 그은 선은 그 위에 별도 레이어(딥색 100%, 굵기 100)로 얹히고,
가이드는 다 그어도 사라지지 않습니다.

## 구조

```
index.html            화면 뼈대
css/app.css           디자인 토큰(색·그림자·간격)과 모든 컴포넌트
js/glyphs.js          획 데이터 — 자음·모음·숫자를 조립해 음절·단어를 만듦
js/curriculum.js      학습 항목(글자·이름·대표 단어·그림)
js/progress.js        별과 잠금 해제, localStorage 저장
js/sound.js           음성합성(ko-KR) + WebAudio 효과음
js/icons.js           시안에 쓰인 SVG 아이콘
js/home.js            홈 · 학습 선택
js/practice.js        연습 3단계, 획 가이드, 그리기 캔버스
js/app.js             화면 전환, 별 표시, 보상 오버레이, 화면 배율
docs/화면시안.dc.html  받은 원본 시안
docs/glyph-sheet.html  전체 글자의 획·획순 점검표
```

### 글자는 어떻게 그려지나

폰트 대신 획 데이터를 씁니다. `js/glyphs.js` 가 1000 × 1000 상자 기준으로
자음 19종 · 모음 21종 · 숫자 10종의 획을 갖고 있고, 음절은 초성 → 중성 →
종성 순서로, 단어는 음절을 나란히 놓아 조립합니다. 조립은 패스 좌표를 직접
옮기는 방식이라 글자를 아무리 겹쳐 넣어도 획 굵기가 균일합니다.

덕분에 `js/curriculum.js` 에 글자만 추가하면 획순·가이드·애니메이션이
전부 따라옵니다. 겹받침·쌍자음·겹모음도 조합으로 처리됩니다.

## 손볼 만한 곳

- **잠금 규칙** — `js/progress.js` 의 `HEAD_START`(기본 3). 처음부터 열어 둘
  항목 수이고, 그 뒤로는 바로 앞 항목을 끝내야 다음이 열립니다.
- **별** — 단계 하나를 끝낼 때마다 1개, 항목당 최대 3개. 줄어들지 않습니다.
- **학습 항목** — `js/curriculum.js` 의 배열에 `[글자, 이름, 소리, 대표 단어, 그림]`
  한 줄을 더하면 됩니다.
- **글자 모양·획순** — `js/glyphs.js` 를 고치고 `docs/glyph-sheet.html` 로 확인.

## 획순 원칙

**위에서 아래로, 왼쪽에서 오른쪽으로.** 모든 획의 진행 방향과 획끼리의 순서가
이 원칙을 따른다. 예외는 아래 세 가지뿐이고, 전부 한글·숫자 쓰기의 관례다.

| 예외 | 이유 |
|---|---|
| ㅓ · ㅕ · ㅔ · ㅖ 는 짧은 가로가 세로보다 먼저 | 교재 획순 |
| ㅜ · ㅠ 는 가로가 짧은 세로보다 먼저 | 교재 획순 |
| 숫자 5 는 위 가로선이 2획 | 세로+배를 한 획으로 이으려면 위 가로선이 뒤에 온다 |

쌍자음(ㄲㄸㅃㅆㅉ)과 겹받침은 **왼쪽 글자 전체 → 오른쪽 글자 전체** 순이고,
복합모음(ㅐㅘㅙ…)은 **구성 모음의 획순을 그대로 이어붙인다**. 두 경우 모두
뒤 자모의 첫 획이 앞 자모의 마지막 획보다 위에서 시작하지만, 자모 단위로 보면
원칙을 지킨다.

동그라미(ㅇ · ㅎ의 아랫부분 · 숫자 0)는 **12시에서 시작해 반시계 방향**으로
하나의 획. 숫자 8은 오른쪽 위에서 시작해 왼쪽 아래로 S자로 내려갔다가
되올라와 시작점에서 닫는 **1획**이고, 9는 원을 완전히 닫은 뒤 그 자리에서
아래로 내려긋는 1획이다.

숫자 1의 갈고리만 왼쪽 아래에서 위로 올라간다. 갈고리와 세로를 한 획으로
이으려면 다른 방법이 없고, 교재도 그렇게 가르친다.

## 알아 둘 점

- 글꼴(Jua · Gothic A1)은 Google Fonts 에서 받아옵니다. 오프라인이면 시스템
  글꼴로 대체되어 모양만 조금 달라집니다.
- 소리는 브라우저 음성합성(ko-KR)을 씁니다. 음성이 없는 환경에서는 효과음만
  납니다. 모바일 브라우저 정책상 첫 터치 이후에 소리가 열립니다.
- 진도는 브라우저별로 저장됩니다(localStorage).
- 시안의 "15개를 넘으면 가로 페이지 넘김" 규칙은 현재 항목 수(최대 21개가
  7열 × 3행, 단어 16개가 4열 × 4행)에서 한 화면에 다 들어와 아직 쓰지
  않았습니다. 항목을 더 늘리면 그때 필요합니다.
