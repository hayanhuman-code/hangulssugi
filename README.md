# 한글쓰기연습 (hangulssugi)

한글 쓰기 연습 웹앱.

## 현재 상태

저장소 초기 세팅 단계입니다. 화면 구현은 Claude Design 시안
(`쓰기연습 앱 화면 시안.dc.html`)을 받은 뒤 진행합니다.

## 결정된 사항

- **결과물 형태**: 빌드 도구 없는 정적 웹앱 (HTML / CSS / JS)
  - 브라우저에서 `index.html`을 바로 열어 실행
  - GitHub Pages 배포 가능
- **화면 설계**: Claude Design 캔버스 시안을 기준으로 구현

## 예정 구조

```
index.html      진입 화면
css/            스타일
js/             앱 로직
assets/         이미지·폰트 등
```
