# 스토어 등록 준비

같은 코드로 웹·안드로이드·iOS 세 곳에 나간다. `index.html` 하나가 세 곳에서
그대로 돌고, 갈라지는 부분만 `native.js` 에 모아 두었다.

```
저장소 루트  ── GitHub Pages (웹 · PWA)
     │
     └── www/ ── Capacitor ── android/  (Google Play)
                          └── ios/      (App Store)
```

## 먼저 알아야 할 것

**빌드는 이 저장소 안에서 끝나지 않는다.**

| 하는 일 | 필요한 것 |
|---|---|
| 웹 배포 | 없음 — `main` 에 올리면 Actions 가 한다 |
| 안드로이드 빌드 | Android Studio (또는 Android SDK + JDK 17↑) |
| iOS 빌드 | **macOS + Xcode**, 그리고 `ios/App` 에서 `pod install` 한 번 |

`npx cap add ios` 는 리눅스에서 만들어 두었으므로 CocoaPods 설치가 아직
안 돌았다. 맥에서 처음 열기 전에:

```sh
sudo gem install cocoapods     # 안 깔려 있으면
cd ios/App && pod install
```

## 개발 흐름

```sh
npm run build     # 웹 자산을 www/ 로 모은다
npm run sync      # build + 네이티브 프로젝트에 반영 (플러그인 갱신 포함)
npm run android   # Android Studio 열기
npm run ios       # Xcode 열기 (맥에서만)
```

웹 파일(`index.html`·`app.js`·`fonts/`…)을 고쳤으면 **반드시 `npm run sync`** 를
돌려야 네이티브 앱에 반영된다. www/ 는 생성물이라 커밋하지 않는다.

## 계정과 비용

| | 비용 | 걸리는 것 |
|---|---|---|
| **Google Play Console** | $25 (1회) | 개인 계정이면 프로덕션 전에 **테스터 12명 × 14일 연속 비공개 테스트**가 의무다. 사람 12명을 먼저 모아야 하므로 여기부터 시작하는 게 빠르다. |
| **Apple Developer Program** | $99/년 | 법인 명의면 D-U-N-S 번호가 먼저 필요하다. 개인이면 바로 된다. |

## 양쪽 공통으로 내야 하는 것

- [ ] **개인정보 처리방침 URL** — `privacy.html` 을 GitHub Pages 로 올린 주소
      (`https://<사용자>.github.io/hangulssugi/privacy.html`). 수집하는 게
      없어도 URL 자체가 필수 제출 항목이다.
- [ ] **스크린샷** — 기기 크기별로 따로 낸다. iPhone 6.7"·iPad 12.9", 안드로이드
      폰·7"·10" 태블릿. `tools/` 에 만드는 스크립트는 아직 없다.
- [ ] **앱 설명·키워드** — README 첫 문단을 그대로 쓰면 된다.
- [ ] **콘텐츠 등급 설문** — 폭력·성적 표현·구매·광고·사용자간 소통 전부 "없음".
      이 앱에는 외부 링크도 인앱 결제도 채팅도 없다.

## Google Play 에서 더 필요한 것

- [ ] **타깃 연령층 설문** — 만 5세 대상이므로 Families 정책이 적용된다.
- [ ] **데이터 보안(Data safety) 양식** — 수집·공유 모두 "없음"으로 낸다.
      진도와 부모가 넣은 단어는 기기 안에만 남으므로 "수집"이 아니다.
- [ ] **앱 서명 키** — Play App Signing 에 맡기고, 업로드 키는 따로 보관한다.
      `*.keystore`·`*.jks` 는 `.gitignore` 에 넣어 두었다. **키를 잃어버리면
      같은 앱으로 업데이트할 수 없다.**
- [ ] `targetSdkVersion` 이 Play 의 최신 요구치를 넘는지 확인
      (`android/variables.gradle`).

## App Store 에서 더 필요한 것

- [ ] **가이드라인 4.2 (최소 기능)** — "웹페이지를 포장한 앱"으로 보이면
      거절된다. 반박 근거는 이미 갖췄다: 완전 오프라인 동작, 네이티브 음성합성,
      기기 저장소에 남는 진도. 심사 노트에 이 세 가지를 적어 두면 좋다.
- [ ] **Kids Category 로 낼지 결정** — 내면 서드파티 분석·광고가 금지되고
      (이미 없다) 외부 링크·구매는 부모 게이트 뒤에 두어야 한다. 이 앱에는
      외부 링크가 없으므로 추가 작업이 없다.
- [ ] **개인정보 '영양성분표'(App Privacy)** — 전 항목 "수집하지 않음".
- [ ] 지원 URL — GitHub 이슈 주소로 충분하다.

## 코드에서 아직 남은 것

- [ ] **폰 화면 레이아웃.** 태블릿(가로·세로)은 잘 나오지만 폰은 좁다.
      폰 세로에서는 상단 카테고리 탭 5개가 서로 겹치고, 폰 가로(844×390)에서는
      카드 한 줄이 눌린다. 심사관은 폰으로 본다. 두 갈래 중 하나를 골라야 한다.
      - 태블릿 전용으로 낸다 (App Store 는 iPad 전용 설정, Play 는 기기 카탈로그에서 폰 제외)
      - 폰 레이아웃을 손본다 (탭 가로 스크롤 + 카드 최소 높이 재조정)
- [ ] **스크린샷 자동 생성** — Playwright 로 기기 크기별 캡처를 뽑는 스크립트.
- [ ] **버전 관리** — `android/app/build.gradle` 의 `versionCode`·`versionName`,
      Xcode 의 Version·Build 를 올릴 때마다 맞춰 주어야 한다.

## 네이티브에서만 달라지는 동작 (`native.js`)

고칠 일이 생겼을 때 헷갈리지 않도록 적어 둔다.

| | 웹 | 네이티브 |
|---|---|---|
| 읽어주기 | Web Speech API | TextToSpeech 플러그인 — **안드로이드 WebView 에는 Web Speech 음성합성이 없어서**, 갈라지지 않으면 안드로이드만 조용해진다 |
| 진도 저장 | localStorage | localStorage + Preferences 사본 (iOS 가 WKWebView 저장소를 비울 수 있다) |
| 뒤로가기 | 브라우저가 처리 | 시트 → 홈 → 종료 순으로 직접 처리 |
| 오프라인 | 서비스 워커 | 자산이 이미 기기 안에 있음. 서비스 워커는 **넣지 않는다** — 스토어로 업데이트해도 옛 파일을 돌려주기 때문 |
