# 설계 참고 자료

## 화면시안-v2.dc.html

Claude Design 캔버스로 그린 「유아 한글·숫자 쓰기 연습 앱 화면 시안 v2」 원본.
브라우저로 열면 그대로 볼 수 있다. 가로 태블릿 1180 × 820 기준, 만 4세 사용자,
채점·오답 표현 없음이 전제다.

담고 있는 것:

| 절 | 내용 |
|---|---|
| 01 | 디자인 시스템 — 색 팔레트, 타이포 스케일, 그림자 3종, 간격·라디우스, 버튼 규격 |
| 02 | 홈 · 학습 선택 — 탭 5개, 항목 수에 따른 그리드 규칙, 잠금 상태 표현 |
| 03 | 연습 화면 3단계 — 보기 / 따라쓰기 / 혼자쓰기 레이아웃과 획 가이드 3층 구조 |

## 이 시안이 v1 에 대해 지적한 것

시안 본문이 이 저장소의 v1 프로토타입을 직접 겨냥해 쓴 문장을 담고 있다.
현재 코드가 이미 해결한 항목도 있으니, 남은 것을 고를 때 기준으로 쓰면 된다.

- **획 가이드** — "굵은 선에 점선 패턴을 넣지 않습니다. 세 층은 각각 다른 요소로
  그리고, 굵기 44 → 5 → 아이콘 순으로 대비를 만듭니다." (현재 `renderStepTrace`
  가 띠 + 점선 + 화살표 + 번호로 이미 이 구조를 따른다)
- **획 색** — "v1 의 `#FFD93D`(노랑)는 획 색에서 제외하고, 별·보상 등 장식 용도로만
  씁니다. 획 색은 캔버스 배경 `#FFFDF8` 대비 4.5:1 이상을 확보한 값입니다."
- **잠금 표현** — "탭하면 흔들림 대신 살짝 통통 튀고 「다음에 만나요」 소리 재생.
  빨강·회색 경고 톤 금지."
- **버튼 자리** — "세 단계 모두 버튼 자리는 왼쪽부터 같은 순서로 고정되어, 없을 때는
  자리를 비우지 않고 뒤 버튼이 당겨오지 않습니다."

## 글꼴에 대한 메모

시안은 아이용 글꼴로 Jua(손글씨풍)를 지정하고 있으나, **실제 방향은 고딕체**다.
아이가 처음 배우는 글자는 기본 서체로 보여 주는 편이 맞다는 판단이며, 이 부분은
시안보다 우선한다.
